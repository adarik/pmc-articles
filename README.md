# Подборка научных статей (PubMed Central)

Коллекция из **65 научных статей** открытого доступа из PubMed Central (NCBI) по теме пневмоцистной пневмонии (*Pneumocystis jirovecii*), интерстициальных заболеваний лёгких и смежных вопросов диагностики.

🌐 **Сайт:** https://adarik.github.io/pmc-articles/

На сайте для каждой статьи есть название, авторы, журнал, год, ссылки на DOI и оригинал в PMC, кнопки «Скачать PDF» и «Открыть», а также дополнительные материалы, если они есть. Статьи можно искать и сортировать по году.

**Как устроены файлы.** PDF и дополнительные материалы хранятся в папке `c/` в виде текстовых фрагментов (base64). При нажатии на кнопку страница собирает файл прямо в браузере и сохраняет его под понятным именем.

Источник: PubMed Central, PMC Open Access Subset. Права на статьи принадлежат авторам и издателям в соответствии с лицензиями каждой статьи.
